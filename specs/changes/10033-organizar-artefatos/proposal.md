# Proposta - Organizar artefatos de Changes

Revisao r2, 14/11/2026. EM_REVISAO_SPEC.

## Objetivo
Organizar revisoes, decisoes, cobertura e evidencias por Change, reduzindo arquivos soltos e preservando rastreabilidade. Melhorar o README conforme o produto publicado, inspirado na organizacao do README do GitHub Spec Kit. Documentar instalacao do proprio CLI com versao escolhida ou ultima versao compativel.

## Escopo e limites
Adaptar produtores, leitores, templates e instrucoes empacotadas, preservar registros antigos e verificar comportamento com testes. O uv ja resolve versoes; nao criar atualizador proprio. Nao migrar historico automaticamente, alterar contratos aprovados, publicar versao ou mudar gates. Atualizar o CLI nao atualiza projetos consumidores.
